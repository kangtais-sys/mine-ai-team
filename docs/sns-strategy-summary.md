# SNS 전략 요약 (MINE 보유 PDF "수익화 단계별 전략" 17단계 → 엔진 적용본)

> 전체 명제: 인스타 키우기 = "좋은 영상" 아님. **반복 가능한 세계관(캐릭터)을 가진 계정이 추천 알고리즘에 맞는 릴스를 꾸준히 공급 → 브랜드가 광고예산 붙이고 싶은 *미디어 자산*이 되는 과정.** 승부 = 기술 아니라 **일관된 취향 + 상업적 재현성.**
> ⭐ 콘텐츠 KPI = 조회수 아님. **저장·공유·댓글·프로필방문·팔로우전환** (구체 목표: 댓글 100). 매일 판매 금지.

## A. 시리즈 구조 (단품 금지 — "구조로 굴린다")
콘텐츠는 매번 새로 기획 X. **3축 시리즈를 반복**(초반 비중 발견60 / 신뢰25 / 캐릭터15):
1. **발견용**(처음 봐도 이해·신규유입): 오늘의 무드 / 3초컷 / "이런 무드 좋으면 저장" / 같은 얼굴 다른 무드.
2. **신뢰용**(예쁘게만 X·전문성): 쿠션/제형 표현차이 / 톤별 발색 / 피부결 포인트 / **광고 같지 않은 제품 연출 팁**.
3. **캐릭터용**(기억·팬화): AI muse의 화장대 / AI가 해석한 루틴 / 이런 날 이런 무드 / 취향의 언어.

## B. 릴스 구조 (첫 3초가 승부)
- 골격: **1초=정지 · 2~4초=궁금증 · 5~10초=보상 약속 · 중반=전개 · 마지막=감정잔상/저장/공유 포인트.** 핵심=정보전달 아닌 **호기심 긴장 유지.**
- 첫 3초 훅 4종: **①얼굴 훅**(정면 클로즈업·시선전환·예상밖 표정) **②결과 훅**(완성컷부터) **③대비 훅**(A/B) **④문장 훅**(한 줄). 좋은 훅=설명 아니라 **멈춤 유도("뭐지?")**.
- 길이: 발견 7~15s / 저장·공유 15~30s / 설명·설득 20~45s. AI는 **짧은 시각충격 + 한 문장**이 잘 먹힘.

## C. ⚠️ 추천 적합성 (이거 어기면 도달 죽음 — 우리 기존 방식 교정)
추천에서 *불리한* 영상: **화면 대부분을 텍스트로 덮음 / 워터마크·로고 박힘 / 저해상도 / 원본 아님(재활용 느낌) / 콘셉트 자주 바뀜 / "기술 과시형"(팔로우 전환 약함).**
→ **교정: 자막은 최소·핵심만(화면 덮지 말 것), 로고/워터마크 스탬프 금지, 고해상, 시그니처 동그라미도 *남발 금지*(레퍼에 그런 강조 있을 때만), AI 티 과시 금지.** (앞서 "자막·동그라미 다 박자"는 추천에 해로움.)

## D. 제품 문법 (광고처럼 안 보이게)
- "제품 들어가도 광고처럼 안 보이는 문법" 확립. **TVCF처럼 만들수록 안 먹힘 → UGC처럼 보이되 브랜드 결 살아있게.** 정보성/취향이 주(主), 제품은 은근히.
- 광고주도 "광고스럽지 않은 광고"를 원함 = 이게 곧 수익화 경쟁력.

## E. 일관성·다양성·AI투명·사실성 (⚠️ 계정 종류로 갈림)
**① 브랜드 계정 (millimilli.kr / millimilli.us) — 사람 *다양성*:**
- ⭐ **전 세계 다양한 사람들이 쓰는 느낌** = 대세감·글로벌·UGC. 인물 풀을 **다양하게**(KR/US·다양한 인종·연령·체형, 각자 자기 일상 배경에서 milli² 사용). 얼굴 고정 X.
- **일관성은 *얼굴*이 아니라 *브랜드 결*에서** — 컬러팔레트·조명·무드·메시지·톤·제품 연출 결은 고정. (드리프트 방지는 *브랜드 룩*에 적용, 인물은 다양.)
**② 페르소나 계정 (유민혜·lala_lounge 등 AI 인플루언서) — 캐릭터 *고정*:**
- 얼굴 3~5장·표정폭·메이크업·헤어·체형·말투·문장구조·소품 = **고정**(재현 가능 계정 = 광고주 선호). PDF 17단계의 캐릭터 일관 = 여기 적용.
**공통:**
- ⭐ **굉장히 사실적(photoreal) 필수** — 인물마다: 자연 피부 질감·모공 살짝 보임·매트, plastic/airbrush/도자기 피부·AI 인공 매끈함·왜곡 금지, 자연광. (Soul V2 톤 기준.) "진짜 사람들이 실제로 쓴다"는 신뢰 + 추천 적합성(고해상).
- AI는 **숨기지 말고 정체성의 일부로** + 협찬 시 투명 공개.

## E-2. 재미 (캐릭터 시리즈 강화 — 공유·팬화 동력)
- 캐릭터용 시리즈에 **상황극·밈·POV·유머·독특한 관점**을 명시적으로(무드만 X). 예: "POV: AI 뮤즈의 ~", 공감 개그, 반전 상황극. → 공유·댓글·팬화.

## F. 캡션·패키징 (7단계)
- 검색 키워드·해시태그는 **캡션에**(댓글 X). 패키징 체크: 커버 한눈에 이해 / 첫 프레임 강함 / 캡션 첫 줄 / 저장·공유 이유 / 프로필 넘어왔을 때 다음 볼 것.
- 캡션 CTR 공식: 댓글 유도·공유 유도(친구 태그)·저장 유도. **신규/실험/니치 = Trial Reels(비팔로워 테스트).**

## G. 지표 (9단계 — 조회수 아님)
조회대비 프로필방문 · 프로필대비 팔로우 · 도달대비 저장/공유 · 팔로워대비 스토리시청 · **릴스유입 후 다음 콘텐츠 소비량.** "100만 조회"보다 "10만인데 팔로워 붙는 릴스."

## H. 90일/수익화 로드맵 (요약)
- 0~30일 포맷실험(시리즈3~5·훅실험) / 30~60일 반응 포맷 압축·얼굴톤무드 고정·핀3 / 60~90일 저장공유 주제 반복·"광고 안 보이는 문법".
- 협찬 = 게시물비 아닌 **미디어 자산 사용 계약**(usage fee·whitelisting·리그램·광고권한·독점기간·지역/언어). 6개월+ = 미디어 자산·고정시리즈 IP화. → **AI는 "에셋형 광고 파트너" 포지션**(제작+광고활용 자산 단가).

## → 엔진 적용 (content-engine-system.md ②③⑤ 재정렬)
- ② 전략: 매일 *단품* 아니라 **시리즈 3축에서 픽**(발견/신뢰/캐릭터 비중 유지) + 캐릭터 일관 + 첫3초 훅 4종 중 택1.
- ③ 블루프린트: 1초정지/궁금증/보상/저장공유 구조 + **자막 최소** + 캡션(키워드·CTR공식) + 제품 은근.
- ⑤ QA: **추천 적합성 체크(텍스트 덮음·워터마크·해상도·콘셉트 일관) + KPI(저장·공유·댓글·팔로우전환) + 광고티 반려 + 캐릭터 일관.**
