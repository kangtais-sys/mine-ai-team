## 1. 분류 — 시트 체계를 정본으로

새로 만들지 않는다. 담당자·Cowork·시트 206건이 이미 이 축으로 돌고 있다.

```
MM - {시장} - {제품} - {대카} - {소카} - {날짜} - {순번}
     MM-KR-AMP-BA-CLOSE-260812-01
     MM-MIST-BA-SMILE-260713-01   (US 는 시장 토큰 생략 관행)
```

| 축 | 값 (실측 빈도) |
|---|---|
| **시장** | US 140 · KR 66 |
| **제품** | AMPOULE 140 · MIST 45 · DUO(앰플+미스트) 21 |
| **대카** = 소재 컨셉 | **BA 93 (45%)** · GLA 49 · OY계열 15(KR) · PRO 7 · INS 7 · CLI 5 · ING 5 · AUT 5 · 기타 |
| **소카** = 샷 타입 | CLOSE 27 · WIDE 27 · DRY 26 · MACRO 22 · MIRROR 22 · PORE · SCAN · VALUE · COUNT · WET |
| **아바타** | `glass_kr1~11`(KR) · `glass2~4`, 인종별(US) — Element 고정 |

### 왜 내 이전 카탈로그를 버리는가

28건 CapCut **자막만** 세어 `AUT`(권위) 79%가 최다라고 했는데, 실제 제작 분류는 `AUT` 5건(3.6%)이고 **`BA`가 45%로 1위**다.
자막의 수사(권위 서사)와 소재의 컨셉(비포&애프터)은 다른 층이었다. MINE 지적이 맞았다 — **이미지가 B&A로 시작한다.**

→ `/api/content/formats` 카탈로그는 시트 대카×소카 기준으로 교체한다.

### 시트에 이미 있는데 내가 몰랐던 축

- **`편집패턴`** — 레이아웃 레시피가 문장으로 기술돼 있다.
  `"볼·코 매크로 split + 하단 훅 + 채점서클(4주) + 배지2(랜덤)"`
  → 블루프린트 생성의 출력 형식을 이걸로 맞춘다. 새 포맷을 발명할 필요 없음.
- **`채점서클`** — 손그림 동그라미의 정식 명칭.
- **`핵심클레임`** — 컴플라이언스 범위가 소재마다 기록됨.

## 2. 데이터 — 무엇을 어디서 보는가

```
제작 기록          성과
소재로그 시트   ←→   Meta Insights      조인키: Meta광고이름 = 소재ID
(206건, 100%)      (훅률·유지율·본→클릭)
                    아마존 SP-API      (US 매출·BSR — 소재별 귀속은 불가)
```

**조인 다리가 이미 있다.** 시트의 `Meta광고이름` 칼럼이 `소재ID`와 같은 값이다.
내가 설계하려던 "소재코드 = 광고 이름" 방식이 이미 운영에 들어가 있었다.

### 성과 7칼럼 — 현재 전부 비어 있음

| 칼럼 | 출처 | 계산 |
|---|---|---|
| 지출$ / 지출₩ | Meta `spend` | — |
| 노출 | Meta `impressions` | — |
| 3초시청 | Meta `actions[video_view]` | — |
| **훅률** | | 3초시청 ÷ 노출 |
| 클릭 | Meta `outbound_clicks` | — |
| 구매 | Meta `actions[purchase]` | KR 자사몰만 유효 |
| **판정** | | 훅률/유지율/본→클릭 3지표 → 위너·유지·부분수정·폐기 |

담당자가 키값으로 수동 확인하던 자리다. 자동으로 채운다.

### 판정 기준 (2026-09-22 MINE 확정)

| 지표 | 합격 | 경고 | 교체 |
|---|---|---|---|
| 훅률 (3초÷노출) | ≥34% | 14~34% | <14% |
| 유지율 (완주÷3초) | ≥39% | 26~39% | <26% |
| 본→클릭 (클릭÷3초) | ≥39% | 10~39% | <10% |

**위너 = 합격 2개 이상 + 교체 0개** (규칙 A).
3개 동시 요구는 지표가 음의 상관이라 구조적으로 불가능했다 — 훅이 셀수록 아무나 끌어와 클릭 전환이 떨어진다.

**처방** — 1개만 교체면 그 구간만 고친다. 전체 재생성 금지.
`훅률만 낮음 → 앞 3초` · `유지율만 → 중간 재편집` · `본→클릭만 → 엔드카드·CTA` · `2개 이상 → 폐기`

## 3. 매일 어떻게 뽑아내는가

```
07:00  ① 성과 동기화   Meta → 시트 7칼럼 + 판정
       ② 조합 선택     룰 기반 (LLM 0)
       ③ 블루프린트    편집패턴 + 핵심클레임 + 훅 (LLM 1콜)
       ④ 생성          Higgsfield
       ⑤ QA + 코드발급  → 시트 신규행 + 보드 review
       ⑥ 담당자 업로드  Meta 광고이름 = 소재ID 그대로
```

### ② 조합 선택 — 이게 핵심, 그리고 LLM이 필요 없다

매일 N건을 이 비율로 뽑는다. 기존 문서의 시리즈 3축(발견60/신뢰25/캐릭터15)과 같은 사고다.

| 비율 | 무엇 | 규칙 |
|---|---|---|
| **60% 증량** | 위너 조합의 변주 | 판정=위너인 `대카×소카`에서, 소카 또는 아바타만 바꿔 재생산 |
| **30% 탐색** | 미탐색 칸 | 소재 0건이거나 표본<3인 `대카×소카` 조합 |
| **10% 리믹스** | 부분수정 대상 | 처방이 `앞 3초`/`엔드카드`인 소재의 해당 구간만 교체 |

**금지 규칙** (직전과 같으면 거른다)
- 같은 `대카×소카` 2일 연속 금지
- 같은 아바타 3일 연속 금지
- 판정=폐기 조합은 14일 쿨다운

> 선택이 룰이라 토큰이 안 든다. LLM은 ③ 블루프린트 1콜에서만 쓴다.

### ③ 블루프린트 — 출력 형식은 시트 칼럼 그대로

LLM이 만들 것은 신형식이 아니라 **시트에 들어갈 4개 값**이다.

```
편집패턴   "볼·코 매크로 split + 하단 훅 + 채점서클(4주) + 배지2(랜덤)"
핵심클레임  "같은 사람 볼이에요. 단 4주간의 차이. / 엑소좀 개발자가 만든 · 물광 단백질앰플 / CTA 품절 전에"
아바타     glass_kr7   (로테이션에서 배정)
원본       nano_banana_pro + Element MM-kr7 / 한국 침실 아침
```

제약(프롬프트에 박음):
- **비주얼 규칙**: `ad-creative-system.md` — 흑백, Noto Sans KR, 헤드라인 900, 채점서클 검정 1곳, 직각
- **컴플라이언스**: 입증 범위만(24h 보습·결 정돈·팔자/눈가 4주·탄력) · AI 연출 명시 · KR/US 수치 혼용 금지
- **트랙 구분**: 광고 소재에 오피셜 KPI(댓글 유도) 적용 금지 — 실측 4%

### 일일 생산량

현재 실적 기준 **US 5건 + KR 3건 = 8건/일** 을 상한으로 둔다.
(US 140건 / 약 2개월 ≈ 일 2~3건. 자동화로 2배까지가 현실적)

## 4. 만드는 순서

| | 단계 | 산출 | 왜 이 순서 |
|---|---|---|---|
| **1** | **성과 → 시트 기록** | 7칼럼 + 판정 자동 | 이게 없으면 2·3의 근거가 없다 |
| **2** | 카탈로그 교체 | 시트 대카×소카 기준 | 성과가 붙어야 어느 조합이 이기는지 나옴 |
| **3** | 조합 선택 룰 | 매일 8건 자동 선정 | 룰이라 토큰 0 |
| **4** | 블루프린트 생성 | 시트 신규행 | LLM 1콜 |
| **5** | 생성 + QA | 보드 review | Higgsfield |

**1번부터.** 나머지는 전부 성과 숫자 위에 서 있다.

## 5. 정직한 한계

- **US 구매 귀속 불가** — 아마존 랜딩이라 Meta가 구매를 못 받는다. US `구매` 칼럼은 비워두고 `훅률·클릭`으로만 판정.
- **유지율·본→클릭은 영상만** — 정적 소재는 훅률 하나로 판정할 수밖에 없다.
- **표본 부족** — 대카×소카 조합당 1~3건뿐인 칸이 많다. 판정은 표본 3건 이상부터.
- **아마존 스폰서광고 혼입** — US 매출에서 Meta 기여분을 가를 수 없다(담당자가 따로 운영).
