# 숏츠 제품화 — 포맷 라이브러리 (화·목·금·일 로테이션)

> 목적: 잘 나가는 뷰티 숏츠를 **씬별 분석(Higgsfield video_analysis)** 으로 디테일까지 떠서, milli²로 **오리지널 제품화**. "형태만"이 아니라 *디테일(분할·조명대비·ASMR 비트·페이싱)* 까지 복제.
> 저작권 선: 원본 영상·오디오·대사·얼굴 1:1 복제 금지. **크래프트(구조·타이밍·조명·전환)만** 학습 → 우리 제품·footage·사운드로 재현.
> 매번 다르게: 아래 엔트리를 로테이션(같은 포맷 연속 금지).
>
> **⛔ KPI 필수 체크 (모든 숏츠 — 없으면 발행 금지):**
> - **① 진짜 궁금증(curiosity gap)**: 훅이 정보를 다 주지 않고 갭을 연다(반전·미스터리·결과 선공개+과정 보류). 답을 보려면 끝까지/저장하게.
> - **② 대세감(momentum)**: 움직이는 수치·군중 신호("지금까지 N만+ 관심"·"1분 완판"·"요즘 다들 ~"·후기 더미).
> - + 댓글 가르는 질문 / 저장 유도 / 정보성 우선(제품 은근히 1곳).
> - virality_predictor의 hook strength·retention 점수로 ①을 교차검증.

## #1 — Split Problem/Solution (4행 동시 대비)
- **출처(학습용)**: Song of Skin "Problem vs. Solution Skincare Edition" (yt 6xuDNHrYtB4, 2만). video_analysis 615c286b.
- **게이트**: G1 제품적합 ✅(스킨케어 솔루션) · G2 저작권 ✅(분할 before/after는 공용 트렌드).
- **디테일 DNA**:
  - 구조: 4행 가로 분할 지속. **좌=고민 익스트림 클로즈업 / 우=제품 사용·결과.** 순차 아닌 **동시 대비**(3초 즉시 가독).
  - 조명: 밝은 메디컬톤 + 강한 스펙큘러 → 글래스스킨 광. **좌 매트·거침 vs 우 광·매끈 대비 최대화**.
  - 페이싱: 3씬×3s≈9~10s. 훅(0–3 분할+고민) → 사용(3–6) → 페이오프(6–9 세럼 흐름·흡수·플럼핑 ASMR).
  - 톤/컬러: 차분·만족 ASMR / 쿨화이트+스킨톤, 하이라이트 고채도.
- **milli² 제품화 매핑**:
  - 좌(고민) 4행: 속건조 각질 / 화장 들뜸(cakey) / 칙칙함 / 모공·번들.
  - 우(해결): milli² 미스트 *칙—* 분사 → 속부터 차오르는 물광 글래스스킨.
  - 자막(살짝): 좌 "dry, cakey, dull" / 우 "one mist →" + 🫧💧. 끝 질문 "세수 후 몇 초에 뿌려?"(댓글).
  - 사운드: 앱 트렌딩/로열티프리(원곡 복제 X). 캡션: 무드+1+1 프로모.
- **생성 레시피(Higgsfield MS)**: product=milli² 미스트(d3d47aeb), preset=UGC 또는 Product Review, prompt=위 분할·조명대비·분사→물광 디테일 명시. 9:16. virality_predictor 점수 후 채택.

## #2 — 팔자미스트 (smile-line before/after + 시그니처 동그라미)
- **출처(학습용)**: yt smile-lines 트렌드(RY16wLhymz0 explainer + "smile lines removal" 숏츠군 121만~195만 뷰). video_analysis 4e793266.
- **게이트**: G1 ✅(미스트가 팔자 솔루션) · G2 ✅(smile-line before/after는 수많은 크리에이터 공용 트렌드).
- **컨셉**: 건조해서 꺼져 보이던 **팔자 부위가 미스트로 도톰·물광**, 1~4주 before/after. 팔자 위주.
- **디테일 DNA**: 따뜻 정면광·코지·글래스스킨. 비트: 반전훅(팔자 가리킴) → 팔자 클로즈업(건조·꺼짐) → 미스트 분사·톡톡(ASMR) → 도톰·물광 페이오프 → (옵션)1~4주.
- **카피(임상 입증 범위)**: 훅 "팔자, 주름인 줄 알았죠? 사실 '건조'였어요" / 대세감 "1~4주 뿌린 사람들 다 도톰해졌다는 그 미스트 🫧" / 댓글 "너도 팔자 건조함?" / 캡션 1+1 24,900 + "*AI 연출 · 임상 입증 범위 내".
- ⚠️ **컴플라이언스**: "팔자 제거/구조 차오름" 금지 → *수분으로 도톰·라인 부드러워 보임*(겉보기). 임상 데이터가 입증한 워딩만.
- **생성 레시피**: kling3_0 9:16, 팔자 타이트 클로즈업 프롬프트(콧방울→입꼬리 주름선 고정). ⚠️ AI는 팔자 위치·동그라미를 일관되게 못 맞춤 → **시그니처 동그라미는 오버레이 단계에서**(아래).

## 🖍️ 오버레이 단계 (footage 생성 후 — 엔진 필수 부품)
- 힉스필드는 *우리 시그니처 손그림 펜써클*을 정확/일관되게 못 그림 → **footage 위에 우리 렌더러로 오버레이**:
  1. **시그니처 팔자 동그라미**(브랜드 손그림 ellipse SVG, roughEllipse 스타일)를 *정확한 팔자 위치*에 합성(애니메이트 draw-on 가능).
  2. **자막 burn-in**: 반전훅·1~4주·도톰물광·댓글 가르기·1+1·"AI 연출/임상범위".
  3. **사운드**: 로열티프리/앱 트랙(원곡 복제 X) 또는 kling 원음.
- **한 번 빌드 → 매일 자동**(수동 아님). 입력 {footage_url, circle_xy, captions[], sound}. 9:16 → ingest 보드 시드.
