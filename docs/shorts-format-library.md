# 숏츠 제품화 — 바이럴 릴스 포맷 시스템 (화·목 로테이션)

> 목적: 잘 나가는 뷰티 숏츠의 **크래프트(구조·타이밍·조명·전환·훅)** 를 학습해 milli²로 **오리지널 제품화**. "형태"가 아니라 *디테일(분할·조명대비·ASMR 비트·페이싱)* 까지.
> 저작권 선: 원본 영상·오디오·대사·얼굴 1:1 복제 금지. 크래프트만 학습 → 우리 제품·footage·사운드로 재현.
> 매번 다르게: 8포맷 로테이션(같은 레버 연속 금지). 화·목 2개/주 → **4주 사이클**.

---

## ⛔ KPI 게이트 (모든 릴스 — 충족 못하면 발행 금지)
- **① 진짜 궁금증(curiosity gap)**: 훅이 정보를 다 주지 않고 갭을 연다(반전·미스터리·결과 선공개+과정 보류). 답을 보려면 끝까지/저장하게.
- **② 대세감(momentum/social proof)**: 움직이는 수치·군중 신호("요즘 다들 ~"·후기 더미·"1~4주 뿌린 사람들").
- **③ 댓글 가르기 + 저장 유도 + 공유 트리거** 중 최소 2개.
- **④ 정보성 우선 — 제품은 은근히 1곳.** 광고 톤("우리 제품 좋아요") 금지.
- **⑤ `virality_predictor`** 의 hook strength·retention 점수로 ①②를 교차검증 → 통과분만 보드 review.
- 컴플라이언스: AI 연출 명시 · 입증 범위(24h 보습/장벽/결 정돈)만 · KR/US 수치 혼용 금지 · 원곡 금지.

## 🎬 표준 릴스 아크 (4비트 — 캐러셀 슬라이드 구조의 영상판)
| 비트 | 시간 | 역할 | 규칙 |
|---|---|---|---|
| **HOOK** | 0–3s | 궁금증 갭 + 시각 패턴인터럽트 + 자막 훅 1줄 | 반전/미스터리/결과 선공개. 3초 안에 시선 |
| **전개** | 3–8s | 정보 한 스푼 + 데모(ASMR) | 제품은 손에 살짝 — **라벨 클로즈업 금지**(AI가 글자 뭉갬) |
| **페이오프** | 8–12s | 반전 해소 + 제품 은근 1곳 + 대세감 | 효능 단정 금지(겉보기·입증 범위) |
| **엔드카드** | 12–14s | **진짜 제품 이미지(라벨 정확) + 스펙 1줄 + CTA** | 댓글/저장/공유 트리거 1개 명시 |

> **하이브리드 원칙**: 움직임=AI(seedance), **라벨=진짜 이미지**. 모션 비트에선 병 클로즈업을 피해 라벨 뭉개짐을 원천 차단하고, 정확한 라벨은 **엔드카드(실제 제품컷)** 에만 등장. → 엔드카드는 **전 포맷 공통 표준 마지막 비트**.

## 📚 바이럴 포맷 라이브러리 (8종)

### #1 — 반전 토킹 (Myth-bust UGC) · 레버: 궁금증 갭(최강)
- **컨셉**: 모델이 카메라 보고 통념을 깬 뒤 올바른 법 시연.
- **비트**: 훅(반전 선언) → 왜 그런지 한 스푼 → 올바른 타이밍 시연(분사) → 엔드카드.
- **훅 KR**: "미스트 뿌릴수록 더 당겨요? 거꾸로 쓰고 있어서예요" · **US**: "Mist making your skin *drier*? You're using it backwards."
- **대세감**: "요즘 다들 토너 직후 + 마지막에 한 번 더" / **댓글**: "넌 세수 후 몇 초에 뿌려?"
- **생성**: seedance(토킹 UGC, 제품 손에 살짝) · **엔드카드 필수**.

### #2 — 팔자/속건조 Before·After · 레버: 만족 변신 + 시그니처 동그라미
- **컨셉**: 건조해 꺼져 보이던 팔자가 미스트로 도톰·물광(겉보기).
- **비트**: 반전훅(팔자 가리킴) → 팔자 클로즈업(건조·꺼짐) → 분사·톡톡(ASMR) → 도톰·물광 → 엔드카드.
- **훅 KR**: "팔자, 주름인 줄 알았죠? 사실 '건조'였어요" · **US**: "Thought it was a wrinkle? It was just *dryness*."
- **댓글**: "너도 팔자 건조함?" / **컴플라이언스**: 제거/구조 차오름 금지 → *수분으로 도톰·라인 부드러워 보임*.
- **생성**: seedance 팔자 타이트 → **시그니처 팔자 동그라미는 오버레이 단계**(circle_xy). 엔드카드.

### #3 — Split 동시대비 (Problem/Solution) · 레버: 3초 즉시 대비
- **컨셉**: 화면 분할 좌=고민(속건조·들뜸·칙칙·번들) / 우=미스트 후 물광. **순차 아닌 동시**.
- **비트**: 훅(분할+고민) → 분사 → 우측 물광 블룸(ASMR) → 엔드카드.
- **훅 KR**: "왼쪽 나, 오른쪽 나 — 차이는 미스트 한 번" · **US**: "Same face. One side got the mist."
- **댓글**: "세수 후 몇 초에 뿌려?" / 조명: 쿨화이트 + 좌 매트 vs 우 광 대비 최대.
- **생성**: seedance split-screen. 엔드카드.

### #4 — ASMR 30초 결과 (매크로) · 레버: retention + 만족
- **컨셉**: 인물 없이 피부 매크로 — 미스트 입자·흡수·물광 30초.
- **비트**: 훅("30초 만에 물광 실화?") → 매크로 분사·입자 → 흡수·광 페이오프 → 엔드카드.
- **훅 KR**: "30초 만에 물광 되는 거 실화?" · **US**: "Glass skin in 30 seconds — real?"
- **댓글**: "진짜 30초임?" / 사운드: 생성 ASMR(원곡 금지).
- **생성**: seedance 매크로(무인물, 제품 입자). 엔드카드.

### #5 — 꿀팁 N (저장각) · 레버: 저장(최강)
- **컨셉**: "물광 24h 유지 3가지" 빠른 컷 — 가치는 **자막**에 담고 마지막이 핵심.
- **비트**: 훅("3가지, 마지막이 핵심") → 1·2·3 빠른 시연 + 자막 → 3번에서 미스트 은근 → 엔드카드.
- **훅 KR**: "물광 24시간 가는 3가지, 마지막이 진짜" · **US**: "3 ways to lock in glow — #3 is the one."
- **저장**: "저장만 하고 안 할 거지?ㅋ" / **댓글**: "너 몇 번 하고 있어?"
- **생성**: seedance 루틴 빠른컷 + **자막 burn-in 비중↑**. 엔드카드.

### #6 — 실후기 리액션 · 레버: 신뢰 + 대세감
- **컨셉**: **실제 후기 캡처(자사몰/아마존)** 를 띄우고 모델이 공감 반응. ⚠️ 가짜 후기 렌더 금지(CLAUDE 규칙 2).
- **비트**: 훅(후기 캡처 줌인 "이거 내 얘기") → 공감 한마디 → 미스트 시연 → 엔드카드.
- **훅 KR**: "이 후기 보고 산 사람 나뿐 아니지?" · **US**: "This review is *so* me."
- **댓글**: "이런 경험 있어?" / **자산**: 실제 캡처 필요 → **Cowork 캡처 제공**(AI 생성 X).
- **생성**: 실캡처 + seedance 리액션 합성(또는 캡처 위 자막). 엔드카드.

### #7 — POV 상황극 · 레버: 공유(최강)
- **컨셉**: 공감 상황 POV — "에어컨방 6시간 / 회식 다음날 / 면접 5분 전".
- **비트**: 훅(상황 POV 자막) → 떡진·건조 피부 → 미스트로 리셋 → 엔드카드.
- **훅 KR**: "에어컨방에서 6시간 버틴 내 피부 POV" · **US**: "POV: 6 hours in AC air."
- **공유**: "에어컨방 같이 쓰는 사람 태그" / **댓글**: "너 사무실도 이래?"
- **생성**: seedance 상황 UGC. 엔드카드.

### #8 — 트렌드 편승 · 레버: 대세감 + 알고리즘
- **컨셉**: 현재 트렌딩 포맷/오디오/전환을 milli²로 제품화(크래프트만 차용).
- **비트**: 트렌드 훅 → 트렌드 전환에 제품 데모 얹기 → 페이오프 → 엔드카드.
- **훅**: 트렌드별(분석 시점 최신). 사운드는 **발행 앱에서 트렌딩 오디오 입힘**(파일엔 생성음).
- **댓글/공유**: 트렌드 결에 맞춰. / **갱신**: virality 스캔으로 분기마다 교체.
- **생성**: seedance + 트렌드 전환. 엔드카드.

## 🖍️ 오버레이 단계 (footage 생성 후 — 엔진 필수 부품)
힉스필드는 시그니처 손그림 펜써클·정확한 텍스트를 일관되게 못 그림 → **footage 위에 우리 렌더러로 합성**:
1. **시그니처 팔자 동그라미**(roughEllipse SVG)를 정확한 위치에(circle_xy). (#2 전용)
2. **자막 burn-in**: 반전훅·대세감·댓글 가르기·"AI 연출/입증 범위". (satori+resvg, Pretendard)
3. **엔드카드 합성(신규)**: 모션 클립 끝에 **진짜 제품 이미지(라벨 정확) + 스펙 1줄 + CTA** 1.8s concat. → 라벨 100% 정확.
4. **사운드**: 생성음/로열티프리 유지(원곡 금지).
- 입력 `{footage_url, circle_xy, captions[], sound, endcard_url, endcard_text, endcard_sub}` → 1080×1920 → 보드 review 시드. **한 번 빌드 → 매일 자동.**
