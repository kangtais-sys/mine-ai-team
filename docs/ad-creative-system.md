## 3. 타이포

| 역할 | 값 |
|---|---|
| 폰트 | **Noto Sans KR 한 종.** 명조·모노 혼용 금지 |
| 헤드라인 | **900 허용** ← 광고 소재만. 자간 타이트(-1 ~ -2) |

## 4. 컬러 — 흑백 + 라임 포인트 1색

```
#FFFFFF 화이트 · #0A0A0A 블랙 · #F7F6F4 쿨그레이 · #9A9A95 보조텍스트
+ 라임 — 배지 포인트 전용
```
- 기본은 흑백. **유채색은 사진 + 라임 배지뿐.**
- ⚠️ 따뜻한 베이지 금지.
- 모서리 **직각**. CTA 는 **검정 알약(pill)**.

> 2026-09-22 정정: 앞서 "흑백만"이라 적었으나 소재로그 편집패턴 실측에
> `검정칩+라임 배지` 가 v6 사양으로 명시돼 있다. 오피셜 카드(완전 흑백)와 다른 지점.

## 8. 영상 소재 — 골격 (CapCut 28건 실측)

```
캔버스  1080×1920
길이    14.9초 (중앙값 · 6.8~19.5)
컷      8컷 (중앙값) · 컷당 1.9초
전환    없음 — 28건 중 1건만 사용. 사실상 전부 하드컷
효과    거의 없음 (당황한 얼굴 2건)
BGM     있음 / **SFX 0건**
자막    컷마다 1개 · 훅은 첫 자막
```

**시각 구조 — 비교를 한 프레임에 넣는 것이 핵심.** 아래 중 하나 필수.

| 구조 | 형태 |
|---|---|
| **A. 하단 B&A 삽입** | 상단 실인물 / 하단 1/3 비포&애프터 |
| **B. 전면 좌우 분할** | 화면 전체가 좌=칙칙 / 우=글래스스킨 |
| **C. PIP 삽입** | 큰 얼굴 위 작은 창으로 다른 컷 |
| D. 구조 없음 | 셀피 + 텍스트만 (리스티클 등) — 예외 |

> A·B·C 셋 다 원리는 같다. **비교.** MINE: "이미지는 비포&애프터로 시작해 거의 다. 그게 제일 후킹이 좋고."

**반복 장치 빈도** (28건)
```
권위(의사·개발자) 79% · 랭킹·베스트셀러 43% · 게이트키핑 39%
상황극 POV 39% · 반전 39% · 필러 대비 32% · 임상수치 25% · 희소·긴급 21%
댓글 유도 4%  ← 오피셜 KPI(댓글 100)를 광고에 적용하지 말 것
```

**사운드 정책** — 영상 파일엔 BGM/생성음만. 원곡 복제 금지.
트렌딩 오디오는 **발행 단계에서 플랫폼 앱으로** 입힌다.

## 10. 미확인 / 남은 것

- **거리의 대형 미스트 씬** — 커버(첫 프레임)엔 없음. 중간 컷에 있는 것으로 보임. `scripts/extract-frames.mjs` 로 추출 필요.
- **SFX** — CapCut 파일에 0건. 실제로 안 쓰는지, 다른 곳에 저장되는지 미확인.
- **`MM_소재로그_LIVE` 연결** — 시트 ID 확보 시 `readSheet()` 로 붙일 수 있음.
