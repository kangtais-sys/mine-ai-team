# MILLI 제품별 임상 근거 · 합법 클레임 셋 (엔진 컴플라이언스 기준)

> 근거: 밀리밀리 임상 평가표 + **각 제품 상세페이지(millimilli.kr) 문구가 최종 source-of-truth.**
> 규칙: 콘텐츠 카피는 *상세페이지에서 쓰는 문구를 verbatim 미러링* + 아래 입증 범위 안에서만. 입증 밖 표현 금지.

## 제품별 임상 입증 (4주 안면부 시험 = 광고 가능 "개선" 범위)
### 500달톤 프로틴 미스트 (주름)
- 24시간 보습 유지력 (전완부)
- **팔자주름 개선** (4주) — 이미지·데이터·그래프
- **눈가 주름개선** (4주)
- **볼부위 피부 꺼짐 개선** (4주)
- 콜라겐 생성 증가 유전자 발현 (**in-vitro, 비인체시험**) ⚠️ 아래 주의
### 앰플
- 피부 리프팅 개선 (4주) · 모공부위 피부 탄력 개선 (4주)
### 비타미스트 (미백)
- 피부 윤기(광채) 개선 · 피부톤(밝기) 개선 · 색소침착(기미·잡티) 개선 (4주)
### 시카미스트
- 피부 진정(붉은기) 개선 · 피부 장벽(TEWL) 개선 · 피부 자극(피지양) 개선 (4주)
### 4종 공통
- 민감성피부 1차 자극테스트(3D) · 안전성 보고서.

## ⚠️ 표현 규칙 (의약품 오인·과대광고 방지)
1. **"주름 개선"류**는 **기능성화장품(주름개선) 등록**이 전제 — 등록 범위 내 표현만. (등록 여부 확인 필요.)
2. **"콜라겐 생성"**: in-vitro 유전자발현 데이터라 **대중 광고 헤드라인에 단정 금지**(의약품 오인 고위험). → 상세 근거에만, 또는 "콜라겐 생성 증가 유전자 발현 (in-vitro 시험)" 단서 필수.
3. ⛔ 금지: "팔자 채워진다/펴진다"(구조 단정·즉시), "한 번에/즉시" (4주 누적 시험이므로 *4주 꾸준히* 프레임).
4. ✅ 권장 프레임: "**4주 꾸준히** 쓰면 팔자·눈가 **주름 개선**(임상)", "탄력 있어 보이는", "볼 꺼짐 개선(4주)", "24시간 보습". 출처 단서("4주 인체적용시험"·"AI 연출") 병기.
