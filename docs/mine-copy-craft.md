> 출처: `MM_소재로그_KR_LIVE` 66건 · `MM_소재로그_LIVE`(US) 140건의 `핵심클레임`·`편집패턴`·`원본` 칼럼.

## 1. KR 워딩 — 6가지 문법 (고유 66종에서)

### ① 동일인 대비 — "같은 사람" 선언
변화를 주장하지 않고 **조건이 같다는 것부터 못박는다.** 보정 의심을 3초 안에 차단하는 장치.
```
같은 사람 볼이에요. 단 4주간의 차이.
왼쪽이 4주 전이에요. 같은 볼입니다.
볼만 보세요. 4주 만에 이렇게 돼요.
```
> 어디를 볼지 지정(`볼만 보세요`)하는 게 핵심. 시선을 고정한다.

### ② 가격 대비 — 시술·대안과 금액을 나란히
```
100만원대 관리 대신 1만원대 단백질앰플.
피부과 예약 취소했어요. 앰플 하나 때문에.
```

### ③ 시간 지정 민낯 — 구체적 시각으로 진짜임을 증명
```
아침 6시, 민낯이에요. 진짜 엑소좀 개발자가 만든 물광앰플을 발랐거든요.
아침 7시. 민낯이에요. 물광앰플만 발랐어요.
```
> `아침 6시`·`7시` 같은 **구체 시각**이 "연출 아님" 신호로 작동.

### ④ 증상 지목 → 원인 뒤집기
독자가 아는 증상을 먼저 말하고, 원인을 통념과 다르게 짚는다.
```
오후만 되면 들뜨죠? 그거 속건조예요.
3시만 되면 각질 올라오죠? 크림 말고 단백질앰플이요.
오후에 화장 밀리죠? 기름 아니라 수분 부족이에요.
```
> 구조: `{시각} {증상}죠? {통념}이 아니라 {진짜원인}이에요`

### ⑤ 부정 선언 — "~아니에요"
```
이거 필터 아니에요. 단백질만 32종. 한 병에 다 들었어요.
파데를 끊었어요. 단백질앰플 하나로.
```

### ⑥ 성분 수치
`109가지 성분` · `단백질만 32종` · `500달톤` — 숫자를 그대로 노출.

### CTA — 전부 다르게 씀 (반복 금지)
```
품절 전에 사기 · 오늘 특가로 사기 · 내일 도착 받기 · 지금 사러 가기
바로 사러 가기 · 품절 임박 구매 · 오늘만 이 가격 · 지금 주문하기
내일 받아보기 · 바로 구매하기 · 재입고 전 구매 · 오늘 특가 받기
바로 결제하기 · 내일 아침 받기
```
> 66건 중 CTA가 거의 겹치지 않는다. **긴급(품절·임박) / 가격(특가·오늘만) / 배송(내일 도착)** 3계열을 돌려 쓴다.

### 문체 규칙
- **해요체 구어** — `~이에요` `~했어요` `~죠?`
- **짧은 단문 2~3개**로 끊는다. 한 문장에 한 정보.
- 1인칭 체험 (`제가` 생략형)
- 물음표로 공감 유도 후 단정으로 답

## 2. US 워딩 — 같은 축, 다른 결 (고유 131종)

```
Left is her. Right is her 4 weeks later.   ← ① 동일인 대비
Same girl. 28 days apart.
That's not a filter. That's $15.99.        ← ⑤ 부정 선언 + ② 가격
Pores gone. Not photoshop.
$1,000 시술 vs $15.99                       ← ② 가격 대비
Everyone asks. It's $15.99.
Korean girls actually use                   ← 대세감
Nobody said no / 4주 n=20 / TheK           ← 임상 근거
```

**KR과 문법은 같고 표현만 다르다.**
- `Same girl. 28 days apart.` = `같은 사람 볼이에요. 단 4주간의 차이.`
- `That's not a filter.` = `이거 필터 아니에요.`

**US 고유 요소**: 달러 금액을 문장에 직접 박음(`$15.99`), 임상 표기(`n=20`, `TheK`), 랭킹(`올영#1`, `아마존#38`).

## 3. 편집패턴 — 버전 관리되는 생성 레시피

단순 설명이 아니라 **엔진 사양**이다. `v6`·`v7`·`v9.1` 로 버전이 올라간다.

```
v9.1 · 비포 절반만 교체(애프터 원본 유지) · 눈 사이 거리 정렬 · 훅 75px 확대 + 카피 단축
     · 제품 온전 노출 · 게이트 8종 전량 통과

v7  · BA 세로반분할 5구도(SPLIT/CLOSE/WIDE/DRY/MAKEUP) · 다중 얼굴 게이트
     · 명도대비 게이트(가로 120px 구간측정)
     · 사진 사전검사 photocheck(OCR 글자·얼굴수·턱위치·이음매·좌우확대율)
     · 아바타 20명 풀 회전 원장

v6  · 물광 강화 사진 교체 · 얼굴 가림 게이트(눈 구역 침범 0) · 배경여백 게이트
     · 명도대비 게이트 · 배지 시드 고정 · 훅 Noto Sans 300+900
     · 검정칩+라임 배지 · 검정 알약 CTA
```

### 여기서 읽히는 디자인 사양

| 요소 | 값 |
|---|---|
| **훅 타이포** | `Noto Sans 300+900` — 얇은 두께와 900을 **한 훅 안에서 섞는다** |
| **배지** | 검정칩 + **라임** 배지 · 시드 고정(랜덤이되 재현 가능) |
| **CTA** | **검정 알약**(pill) 형태 |
| **채점서클** | 손그림 동그라미. `채점서클(4주)` `채점서클($15.99)` `채점서클(속건조)` — 괄호 안이 강조 대상 |
| **제품 오버레이** | 앰플 2병 좌/우 배치 · 제품컷 누끼 우하단 |
| **해시 배지 2개** | `[#엑소좀 개발자가 만든 + #물광 단백질앰플]` 랜덤 2개 조합 |

> ⚠️ **라임 배지**는 내가 "흑백만"이라고 정리한 것과 충돌한다.
> 정적 광고 소재는 흑백 + **라임 포인트 1색**이 맞다. `ad-creative-system.md` §4 수정 필요.

### 품질 게이트 (자동 검사 8종)
```

다중 얼굴 게이트(분할컷 얼굴 2개 전부 검사) · 눈 사이 거리 정렬
photocheck(OCR 글자·얼굴수·턱위치·이음매·좌우확대율)
```
> 생성물을 그냥 쓰지 않고 **기계적으로 검사해 걸러낸다.** 자동화 시 이 게이트를 반드시 승계할 것.

### 구도 5종 (BA 세로반분할)

## 5. 생성 프롬프트에 박을 것

1. **카피는 위 6문법 중 하나로.** 새 스타일 발명 금지.
2. **CTA는 3계열(긴급·가격·배송)에서 돌려 쓰되 직전과 겹치지 않게.**
3. **훅 타이포 `300+900` 혼용** — 한 훅 안에서 두께 대비.
4. **채점서클은 1곳**, 괄호 대상(기간·가격·증상) 지정.
5. **배지 2개 랜덤 + 시드 고정.**
6. **게이트 8종 통과 전 보드 시드 금지.**
7. **아바타는 Element 풀에서 회전**, 연속 중복 금지.
