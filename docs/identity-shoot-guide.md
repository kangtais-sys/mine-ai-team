## 1. 촬영 환경 셋업

### 조명
- **자연광 (창가, 오전 10시~오후 2시)** 또는 부드러운 디퓨저 조명
- 정면광 우선, 측면광은 보조 (그림자 강하면 NG)
- 색온도 5000K~5500K (K-뷰티 톤 기본)

### 배경
- 단색만: **베이지 / 그레이 / 화이트 / 페일 핑크** 중 택
- 패턴/텍스트/소품 일절 없음
- HeyGen Avatar IV는 배경 단순할수록 결과 좋음

### 메이크업
- **K-뷰티 살구 톤** (LUT와 어울리도록)
- 글로우 베이스 → 코랄/피치 블러셔 → 자연 립
- 컨실러 강하지 않게 (피부 텍스처 살리기)
- 아이라이너 약하게, 마스카라 자연스럽게

### 의상
- 무지 톤온톤 (베이지/아이보리/소프트 핑크)
- 로고/패턴 없음
- 상의 위주 (얼굴+상반신 중심 촬영)

### 장비
- iPhone 15 Pro 이상 또는 미러리스
- **1080p 이상**, 가로/세로 둘 다 촬영
- 삼각대 필수 (영상 흔들림 방지)

## 2. 사진 30장 구성

### A. 정면 클로즈업 (5장) — 가장 중요
HeyGen Avatar IV 베이스 후보. 표정만 다르게:
1. 무표정 (자연스러운 살짝 미소)
2. 활짝 웃음 (치아 보임)
3. 놀람 (눈 약간 크게, 입 살짝 벌림)
4. 집중 (정면 응시)
5. 미소 (입꼬리만 살짝)

### B. 측면 좌/우 (각 5장)
1. 정측면 (90도) — 좌/우 각 1장
2. 반측면 (45도) — 좌/우 각 2장
3. 약간 측면 (15도) — 좌/우 각 2장

총 10장

### C. 전신 (5장)
1. 정면 직립
2. 한 발 앞으로
3. 옆모습 전신
4. 살짝 비스듬한 포즈
5. 손동작 자연스럽게

### D. 무지 배경 클로즈업 (5장) — **HeyGen 최우선**
- 어깨 위까지만 프레임
- 배경 완전 단색
- 정면 응시, 자연스러운 표정 5종

### E. 메이크업 룩 변형 (5장)
1. 글로우 베이스 (윤기)
2. 매트 베이스 (차분)
3. 페일 룩 (연한 톤)
4. 살구 풀메이크업 (LUT 기본)
5. 노메이크업 가까운 느낌 (제품 비포 컷용)

## 4. 업로드 가이드

### Supabase Storage 경로
```
creator-identity/
├── photos/
│   ├── frontal-closeup-01.jpg ~ 05.jpg
│   ├── side-left-01.jpg ~ 05.jpg
│   ├── side-right-01.jpg ~ 05.jpg
│   ├── fullbody-01.jpg ~ 05.jpg
│   ├── plain-bg-01.jpg ~ 05.jpg
│   └── makeup-look-01.jpg ~ 05.jpg
└── videos/
    ├── talking-frontal.mp4
    ├── side-walking.mp4
    └── closeup-detail.mp4
```

### 파일 명명 규칙
- 소문자 + 하이픈만
- 한글 파일명 금지 (HeyGen API 호환성)
- jpg/mp4 권장 (heic/mov는 변환 후 업로드)

### 메타데이터 입력 (업로드 후)
`creator_identity` 테이블의 `data.photos[]`에 각 사진의 다음 정보 기록:
```json
{
  "url": "https://...",
  "category": "frontal_closeup",
  "expression": "neutral_smile",
  "is_heygen_primary": true,
  "uploaded_at": "2026-05-26T..."
}
```

`is_heygen_primary: true`로 표시된 1장이 HeyGen Avatar IV의 기본 베이스가 됨. **무지 배경 클로즈업 중 가장 잘 나온 1장 선택.**

## 6. NG 가이드 (이런 거 찍지 말기)

- ❌ 강한 그림자 (반쪽 어두운 얼굴)
- ❌ 패턴 있는 옷 (스트라이프, 체크)
- ❌ 화려한 배경 (포스터, 인테리어)
- ❌ 강한 메이크업 (글리터, 진한 아이라인)
- ❌ 작은 사이즈 (1080p 미만)
- ❌ 흔들린 영상
- ❌ 다른 사람 등장
- ❌ 로고 (옷, 액세서리, 배경)
- ❌ 안경 반사
- ❌ 입 가리는 손동작 (HeyGen 립싱크 학습 방해)
