# 밀리밀리 콘텐츠팀 — 설계 (확정 2026-09-22)

> 전제: **유민혜는 광고 운영자가 아니다.** 광고 집행(Meta·아마존 스폰서)은 팀원이 한다.
> 유민혜의 일 = **데이터를 보고 "팔리는 콘텐츠"를 만드는 것.**
> 실측 근거는 `content-team-research-2026-09-22.md`.

---

## 0. 책임 경계 — 이 설계의 출발점

```
노출 ────────▶ 클릭 ────────▶ 구매
└─── 콘텐츠 책임 ───┘  └─ 오퍼·랜딩·가격·리뷰 책임 ─┘
      (유민혜)              (마케팅팀 · 아마존)
```

소재가 통제하는 건 **멈춰세웠나 / 붙잡았나 / 누르게 했나**까지. 그 뒤 구매는 가격·리뷰·배송이 결정한다.
**ROAS로 소재를 평가하면 랜딩 탓을 소재가 뒤집어쓴다.** ROAS·CPC는 참고 표시만, 판정에는 쓰지 않는다.

## 1. 판정 기준 (확정)

미국 영상 소재 33개 실측 분포의 **상위 25%를 합격선**으로.

| 지표 | 정의 | 합격 | 경고 | 교체 |
|---|---|---|---|---|
| **훅률** | 3초 시청 ÷ 노출 | **≥ 34%** | 14~34% | **< 14%** |
| **유지율** | ThruPlay ÷ 3초 시청 | **≥ 39%** | 26~39% | **< 26%** |
| **본→클릭** | 아웃바운드 클릭 ÷ 3초 시청 | **≥ 39%** | 10~39% | **< 10%** |

**판정 규칙**
- 3개 중 **2개 이상 '교체'** → 폐기
- **1개만 '교체'** → 그 구간만 수정 (전체 재생성 금지)
- 3개 모두 '합격' → **위너.** 해당 조합의 생성 가중치 ↑

**진단 → 처방 매핑** (이게 이 체계의 핵심 효용)

| 나쁜 지표 | 무슨 뜻 | 처방 |
|---|---|---|
| 훅률만 낮음 | 내용은 되는데 첫 3초가 약함 | **앞 3초만 교체** (리믹스) |
| 유지율만 낮음 | 들어왔는데 중간에 나감 | 3~8초 전개 재편집, 길이 단축 |
| 본→클릭만 낮음 | 다 봤는데 안 누름 | 엔드카드·CTA·오퍼 교체 |
| 훅률↓ + 유지율↓ | 주제 자체가 안 먹힘 | 앵글 교체(폐기) |

> 실제 사례: `GLOW3_DESK_BOTTLE` 훅률 4.5%(최저)인데 본→클릭 55.0%(최상위권).
> 폐기 대상이 아니라 **앞 3초만 갈아끼울 후보.** ROAS로는 절대 안 보이는 구분.

**보조 지표** — Meta 상대순위(`quality/engagement/conversion_rank`). 같은 타겟 경쟁 소재 대비 위치라
절대선 없이도 우열을 준다. 현재 US: 참여율 평균이상 33 / 전환율 평균이상 42.

## 2. 분류 체계 — 소재코드

### 2-1. 축 6개 (전부 "만들 때 고르는 것"만. 관리용 메타데이터 아님)

```
AD - US - MST - MYTH - FACE - REEL - 260922 - 01
│    │    │     │      │      │      │        └ 변형 번호
│    │    │     │      │      │      └ 제작일
│    │    │     │      │      └ 포맷
│    │    │     │      └ 훅 타입 (첫 3초가 무엇으로 시작하나)
│    │    │     └ 앵글 (설득 축)
│    │    └ 제품
│    └ 시장
└ 트랙
```

| 축 | 값 |
|---|---|
| **트랙** | `AD` 광고소재 · `OFF` 오피셜 SNS |
| **시장** | `KR` · `US` |
| **제품** | `MST` 단백질미스트 · `AMP` 앰플 · `SET` 세트 · `BRD` 브랜드 |
| **앵글** | `BA` 비포애프터 · `CLI` 임상수치 · `POV` 상황극 · `MYTH` 반전·통념깨기 · `AUTH` 권위(랭킹·리뷰·전문가) · `OFFER` 오퍼·가격 · `TIP` 정보꿀팁 · `UGC` 실후기 |
| **훅 타입** | `FACE` 얼굴클로즈업 · `RESULT` 결과선공개 · `SPLIT` 화면대비 · `TEXT` 문장훅 · `SCENE` 상황 · `ASMR` 질감·소리 |
| **포맷** | `REEL` 영상 · `CARD` 카드뉴스 · `STILL` 정적1장 |

### 2-2. 이 코드가 성과와 제작을 잇는 다리

대시보드가 코드를 발급 → 담당자가 **Meta에 그 이름 그대로** 업로드 → `ad-winners`가 `ad_name`으로 조인.
별도 API 연동·권한 심사 없이 오늘 당장 동작한다.
약점은 담당자가 이름을 바꾸면 끊긴다는 것 → **"코드 없는 광고" 경고 박스**로 매일 잡아낸다.

### 2-3. 기존 소재 백필 (⭐ 새 콘텐츠 없이 즉시 학습)

기존 643개는 레거시 네이밍(`REVIVE_A_1`, `[AUTO] GLOW3_DESK_BOTTLE`, `MM-KR-AMP-BA-WIDE-260819-02`).
**이름 + 썸네일 + 캡션을 LLM으로 읽어 6축을 역분류**하고 `legacy:true`로 저장한다.
→ 백필만 끝나면 **오늘 바로 위너 매트릭스가 나온다.**

### 2-4. 위너 매트릭스

`제품 × 시장`마다 `앵글 × 훅타입` 표를 만들고 각 칸에 **합격률**과 **평균 훅률**을 채운다.

```
US · 미스트            FACE   RESULT  SPLIT  TEXT  SCENE  ASMR
  MYTH  반전            80%     -      50%    33%    -      -
  BA    비포애프터       60%    75%     -      -     -      -
  POV   상황극           -      -       -     20%   70%     -
  ...
```
칸이 곧 **"다음에 뭘 만들지"**다. 빈 칸 = 미탐색, 낮은 칸 = 쿨다운, 높은 칸 = 증량.

## 3. 오피셜 vs 광고 소재 — 같은 축, 다른 문법

| | 오피셜 SNS | 광고 소재 |
|---|---|---|
| 1순위 | 댓글·저장·공유 | 훅률·유지율·본→클릭 |
| 제품 노출 | **은근히 1곳** | 전면 |
| 가격·오퍼 | **금지** | **필수** |
| 뼈대 | 정보가 주인공 | 오퍼가 주인공 |
| 채널 | IG·틱톡·유튜브숏츠 × KR/US (6채널) | Meta 광고계정 |

같은 앵글이라도 결이 다르다.
- `MYTH` 오피셜 → "팔자, 주름인 줄 알았죠? 사실 건조였어요"
- `MYTH` 소재 → "Mist making your skin *drier*? You're using it backwards." + `$14.99` + 권위배지

생성 프롬프트는 **`트랙 × 시장` 4갈래로 완전 분리**한다. KR은 자사몰 1+1 문법, US는 아마존 $14.99 + 사은품 + 임상수치 + 필러 대비 서사.

## 4. 위너·트렌드 소재 찾기

### 4-1. 두 개의 소스

**A. 내부 위너** — 우리 소재를 §1 기준으로 판정. 이미 동작 중.

**B. 외부 위너(트렌드)**
| 소스 | 방식 | 뽑는 것 |
|---|---|---|
| Meta 광고 라이브러리 | 브라우저 스캔(공식 API 막힘) — 장기집행 = 전환 위너 | 훅 문장·앵글·오퍼구조·권위장치 |
| TikTok Creative Center | 브라우저 스캔 | 트렌딩 포맷·전환·사운드 결 |
| YouTube Shorts | Data API (완전 자동) | 문제→해결 구조·리텐션 패턴 |

> 검증됨: 광고 라이브러리는 로그인 없이 조회 가능. 2026-09-22에 millimilli.us 15건을 이 방식으로 읽음.

### 4-2. 훅 라이브러리 — 모든 위너가 모이는 곳

내부·외부 위너 1건 = **훅 카드 1장**.
```
{ 훅문장(KR/US), 앵글, 훅타입, 4비트 구조, 대세감 장치, 출처URL, 성과(내부면 3지표),
  usedIn:[소재코드…], cooldownUntil }
```
이게 **생성의 입력**이다. 트렌드를 "봤다"로 끝내지 않고 재사용 가능한 부품으로 쌓는다.
⛔ 원본 영상·오디오·대사·얼굴 1:1 복제 금지. **크래프트(구조·타이밍·조명·페이싱)만 차용.**

## 5. 어떻게 만들 것인가 — 제작 파이프라인

```
① 조합 선택   위너 매트릭스 상위 2 + 미탐색 칸 1 + 신규 트렌드 1
② 블루프린트  LLM: 훅 3안 · 4비트 구조 · 캡션 · KPI장치 · 컴플라이언스 문구
③ 비주얼      Higgsfield (영상 9:16 / 정적) + ⛔제품은 절대 생성 금지, 실제 제품컷만
④ 합성        우리 렌더러 — 손그림 동그라미 · 자막 번인 · 엔드카드 · 권위배지 · 오퍼밴드
⑤ QA 게이트   아래 체크리스트
⑥ 소재코드 발급 → 보드 review → 승인 → 팀원이 Ads Manager 업로드(이름 그대로)
```

### 5-1. ⭐ 리믹스 경로 (전체 재생성 금지)

§1 진단이 "한 구간만 나쁨"이면 **그 구간만 교체**한다. 실데이터가 요구한 경로다.
- 훅률만 낮음 → **앞 3초 오프닝만** 재생성 후 붙임 → 코드 끝 변형번호만 +1
- 본→클릭만 낮음 → **엔드카드만** 교체
- 유지율만 낮음 → 중간 컷 재편집·길이 단축

기존 소재 33개 중 **훅률만 나쁜 게 5건** 이미 확인됨(GLOW 계열). 여기가 첫 타깃.

### 5-2. 표준 4비트 (영상)
`HOOK 0–3s` 궁금증 갭 + 패턴인터럽트 → `전개 3–8s` 정보 한 스푼 + 데모 → `페이오프 8–12s` 반전 해소 + 제품 은근 → `엔드카드 12–14s` **진짜 제품컷(라벨 정확)** + 스펙 1줄 + CTA

> 하이브리드 원칙: **움직임=AI, 라벨=진짜 이미지.** 모션 비트에서 병 클로즈업 금지(AI가 글자 뭉갬).

### 5-3. 소재 디자인 시스템 (기존 Cowork 작업물에서 확정)
우상단 `milli²` · 초대형 볼드 헤드라인 + **손그림 동그라미 강조** · 권위배지 2단(`TOP 100 AMAZON` / `#1 OLIVE YOUNG`) · 클리니컬 수치 배지 · 하단 **블랙 오퍼밴드** + 가격 + 실제 제품컷 · 최하단 근거 각주

### 5-4. QA 게이트 (하나라도 ✗ = 반려)
☐ 궁금증 갭 + 대세감 둘 다 ☐ 앵글·훅타입이 직전과 다름(로테이션) ☐ 제품 = 실제 에셋만
☐ 9:16 (영상) ☐ 클레임 범위 내 ☐ **KR/US 수치 혼용 금지** ☐ `Created with AI` 명시
☐ 오피셜이면 제품 은근 1곳 / 소재면 오퍼·CTA 존재

## 6. 만들어가는 순서

| | 단계 | 산출 | 상태 |
|---|---|---|---|
| 0 | 데이터 배선 | 광고계정 8개·콘텐츠 지표·판정 기준 | ✅ **완료** |
| 1 | **분류 체계 + 기존 소재 백필** | 위너 매트릭스가 즉시 나옴 | ← 다음 |
| 2 | **성과 화면** | 소재 격자·판정·진단·계열별 승률 | |
| 3 | 훅 라이브러리 + 트렌드 스캔 | 재사용 가능한 훅 카드 축적 | |
| 4 | 생성 파이프라인 (신규 + **리믹스**) | 매일 자동 보드 시드 | |
| 5 | 오피셜 트랙 연결 (6채널) | 댓글·저장·공유 지표 | |

### 보류 (필요해지면)
- **Amazon Attribution** — 소재별 진짜 ROAS. 지금은 마케팅팀 영역이라 후순위.
- 권한 없는 광고계정 4개 `ads_read` 부여.
- `sales/amazon.js` 죽은 AWS SigV4 서명 제거 (동작은 하나 죽은 코드).
