> 목적: **MINE 없이 매일 보드를 D-3까지 "콘텐츠 SET" 단위로 자동 채운다.** KR/US.

## 0. 목표·KPI·레버
- **1순위 = 댓글 100 / 저장 / 공유**(인게이지먼트). 조회수·직접판매 아님.
- 정보성·가치가 주(主), **제품은 은근히 1곳**, 광고/판매 톤 금지. 수익화는 신뢰→**미디어 자산화**(협찬·광고권한)로 따라옴.
- 레버 5종 균형 필수: **후킹 · 재미 · 트렌드 · 정보성 · 사실성**.
- 인물: **브랜드 계정(millimilli)=전 세계 다양한 사람(대세감) / 페르소나 계정(유민혜)=고정 캐릭터.** 둘 다 **굉장히 사실적(photoreal).**

## 0-1. 산출 기본단위 = "콘텐츠 SET" (⛔ 단품 금지)
사진/영상 한 장으로 끝내기 금지. **1 SET = 7요소가 다 묶인 것:**
`①트렌드출처(실제 링크) · ②시리즈축 · ③훅 · ④비주얼(자산) · ⑤캡션 · ⑥KPI장치 · ⑦컴플라이언스`
비주얼은 SET의 부품 하나. 블루프린트가 본체.

## 1. 입력 — 트렌드 (⚠️ "안 보면 안 만든다")
매 SET은 **그날 실제로 스캔한 트렌드 1건에 1:1 추적**(과거기억·추측 금지). **트렌드 출처 = 출력 타입 결정(섞지 말 것):**
- **메타 광고 라이브러리**(키워드·KR/US, 노출/장기집행순) = 전환 위너 → **정적/캡션·UGC 일기톤** 결.
- **유튜브**(키워드+워치리스트, 조회·최근·댓글비) = 오가닉 → **영상(before/after·문제→해결)** 결.
- (보조) 틱톡 Creative Center.
- **키워드 풀(로테이션):** 콜라겐 · 미스트 · 글로잉뷰티 · 글래스스킨 · 탄력 · 팔자주름 · 눈가주름 · k뷰티 · 코리안스킨케어 · 올리브영 · 미백 · 진정.
- **컨텍스트:** 날씨/계절(→고민 앵글) · 실후기 · 라이브 프로모(은근) · 요일/슬롯.

## 2. 전략 (오늘 뭘)
1. **출력 타입(번갈아):** 월·수·토 = **정적(메타 기반)** / 화·목·금·일 = **영상(유튜브 기반)**. → 슬롯에 맞는 소스만 스캔.
2. **고민/키워드 로테이션(매번 다르게, 직전과 다름):**

   | 고민/키워드 | 앵글 예 | 제품 | 클레임(범위) |
   |---|---|---|---|
   | 콜라겐·탄력 | 탄력 떨어진 느낌 | 미스트/앰플 | 탄력 있어 보이는·리프팅 개선(4주) |
   | 미스트·속건조 | 에어컨/환절기 건조 | 미스트 | 24h 보습·결 정돈 |
   | 글로잉·글래스스킨 | 물광 베이스·아침 광 | 미스트/비타 | 윤기·광채 개선 |
   | 팔자·눈가주름 | 주름 케어 | 미스트/앰플 | 팔자·눈가 주름 개선(4주) |
   | k뷰티·코리안스킨케어 | 한국 루틴·꿀팁 | 루틴(제품 은근) | 정보성 |
   | 올리브영 | 올영 랭킹·실후기 | 해당 제품 | 후기·랭킹(실캡처) |
   | 미백·톤·색소 | 칙칙·잡티 | 비타미스트 | 톤·색소 개선 |
   | 진정·붉은기 | 자극·트러블 | 시카미스트 | 진정·장벽 개선 |

3. 픽한 키워드로 **소스 스캔 → 위너 1건**(게이트: 제품적합·저작권·궁금증/대세감·모멘텀) → 훅·포맷·구조 **패턴만 추출**(클론 X).
4. **시리즈 축 로테이션**(발견60 / 신뢰25 / 캐릭터15, 직전과 다름) — 발견=후킹·트렌드 / 신뢰=정보성 / 캐릭터=재미(상황극·밈·POV).

## 3. 블루프린트 (SET 설계 — 매일 100% 자동 산출)
`①트렌드출처(링크) ②출력타입 ③시리즈축 ④훅(3초·4종: 얼굴/결과/대비/문장, *멈춤 유도*) ⑤구조(영상=1초정지·궁금증·보상·저장공유 / 정적=커버·캡션첫줄) ⑥비주얼지시(인물 다양·photoreal·제품 은근=얼굴에 안 들이댐·자막 최소) ⑦캡션(UGC 일기톤+KPI장치+키워드/해시태그+합법 클레임 문구) ⑧사운드(영상=로열티프리/앱, 원곡 금지)`

## 4. 프로덕션
- **비주얼(AI 적합):** 제품·센서리·인물 stills/짧은클립 → Higgsfield. **진짜 제품 레퍼(product-assets media_id) 필수** / **photoreal**(모공·질감, plastic·AI티 X) / **다양성**(브랜드)·**고정**(페르소나) / **제품 은근**(책상·손에 무심코). 모델: 인물무드=soul_2, 제품·텍스트충실=nano_banana_pro/2.
- **영상:** 유튜브 트렌드 기반 before/after·문제해결. ⚠️ **사람 토킹 풀영상·정밀 before/after = AI 가짜 티(한계) → 캡컷 편집/UGC 크리에이터로 라우팅.** 시그니처 표시·자막 = *오버레이로 최소*(추천 적합성).
- **사운드:** 로열티프리/앱. **원곡 금지.** 트렌딩 사운드는 발행 단계에서 틱톡/IG 앱으로.

## 5. QA 게이트 (하나라도 ✗ = 반려·재생성)
☐ **SET 형태**(단품이면 즉시 반려) ☐ **실제 트렌드 1건 추적**(출처 링크·출력타입 일치) ☐ **키워드 로테이션**(직전과 다른 고민) ☐ 궁금증 갭 훅 + 대세감 ☐ 정보성·재미 ☐ **제품 은근(광고티 X)** ☐ **자막 최소·워터마크 X·고해상**(추천 적합성) ☐ **사실성**(plastic·AI티 X) ☐ 다양성(브랜드) ☐ **클레임 범위**(claims-substantiation)·AI연출 명시·KR/US 수치 분리 ☐ **KPI 장치**(댓글 가르기+저장+공유)

## 7. 자동화 런타임 (★ MINE 없이 도는 법)
**한 번만 잠그는 설정(MINE, 매일 아님):** 합법 클레임 셋 · 키워드 풀 · 워치리스트(계정) · 제품 에셋맵(media_id) · 브랜드 룩 · 페르소나 매뉴얼.

**매일 자동(앱=Vercel cron, 항상 켜짐, D-3까지 채움):**
1. **트렌드 스캔** — 유튜브=Data API(완전 자동) / 메타 광고라이브러리=브라우저 스캔(반자동, API 막힘) / 틱톡=보조(반자동).
2. **전략·블루프린트 생성** — 출력타입·키워드 로테이션·위너 추출·SET 설계 (완전 자동).
3. **비주얼 생성** — Higgsfield API 직접호출(persona-soul 패턴 확장: video_analysis·generate_image/video·overlay) + 진짜 제품 레퍼.
4. **QA 게이트** 통과분만 → **보드 시드(review).**
5. **AI 한계분(사람토킹·정밀영상)** → 블루프린트만 자동, 영상은 편집/UGC 라우팅(MINE/팀).

**MINE의 일:** 설정 1회 잠금 + **매일 보드에서 검토·승인** + AI 부적합 컷만 촬영/위임.

## 8. 정직한 한계 (숨기지 않음)
- **메타 광고라이브러리·틱톡 트렌드 = 반자동**(공식 API 막힘 → 브라우저 주기 스캔). 유튜브만 완전 자동.
- **사람 토킹 풀영상·정밀 before/after = 생성AI 한계**(가짜 티) → 편집/UGC. AI는 제품·센서리·인물 stills·짧은클립에 강함.
- **링크→영상 "그대로 복제"는 불가**(생성AI는 클론 아님 + IP) → *포맷·훅·룩 패턴만* 차용해 오리지널.
- **제품 정확도** = 진짜 제품 레퍼 media_id 필수(만료 시 재업로드 / Blob 미러 권장).
- **앱 미오픈 시** Cowork 스케줄은 다음 실행 — 무인 핵심은 Vercel cron이 담당.

## 9. 일 순서 (현재)
**① 키워드 로테이션 돌려 서로 다른 SET(정적1+영상1)을 트렌드 실제 스캔부터 끝까지 완성 → ② MINE OK(기준 확정) → ③ 그 SET 형식·로테이션을 엔진(Vercel cron + Higgsfield API)에 박아 자동화.** QA가 단품·트렌드누락·키워드고착을 강제 반려해 *샘 방지*.
